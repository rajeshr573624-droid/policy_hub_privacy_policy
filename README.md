# PolicyOps Privacy Policy

The privacy policy for the PolicyOps insurance agency CRM, as a single static page (`index.html`).

Publish it with **GitHub Pages** (Settings → Pages → Deploy from a branch → `main` / root). The page is then at
`https://rajeshr573624-droid.github.io/policy_hub_privacy_policy/`. Use that URL as the **Privacy Policy URL** and
**User data deletion** URL (`…/#deletion`) in the Meta app settings.
